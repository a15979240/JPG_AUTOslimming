# 📷 JPG 瘦身工具（JPG Slimming Tool）

- 一款可在手機上一次搞定 JPG 圖片壓縮的 Flutter App。
- 「手動（品質/解析度）」與「自動（目標容量）」雙模式，加上背景自動化、
- 即時監測、狀態列通知、分頁處理清單、明/暗主題與繁中/英文雙語，一應俱全。
- 本專案由AI撰寫。
---

## ✨ 功能特色

### 🎛️ 兩種壓縮模式
| 模式 | 說明 |
|---|---|
| **手動模式** | 自由調整「品質（%）」與「解析度（%）」，所見即所得 |
| **自動模式** | 以「輸出目標容量」為基準（預設 **10MB**，可輸入任意 MB 含 <1MB）|
| —— 自動模式策略 | 品質優先，最低品質下限（預設 80%）；品質無路可退才縮解析度（下限 75%）|
| 跳過下限（策略 A） | 品質 / 解析度**交替均衡降級**（70%→50%→50%→40%…），避免頭重腳輕 |

### 🤖 背景自動化
- **即時監測**（`Directory.watch`）：來源資料夾一有新 JPG 立即自動壓縮
- **定時掃描**（WorkManager，15–1440 分鐘可調）
- 4 種模式：**關閉 / 即時 / 定時 / 兩者**，採 2×2 方格快速切換

### 📢 狀態列通知（不干擾使用者）
- 不開啟 App 就能知道目前狀態：**監控中**、**處理中（第 X / 共 N）**、**已暫停 / 已停止**
- 低重要性、靜音、不震動、不亮燈；滑掉後下一個進度更新仍會重新出現

### 📄 處理區塊
- **分頁顯示**檔案清單：每頁 **5 / 10 / 20** 個，換頁在區塊上方
- **停止 / 暫停 / 繼續**：處理過程中可隨時掌控
- **「是否重新處理相同檔案」開關（預設關閉）**：若輸出資料夾已有「檔名包含來源檔名」的輸出 → 自動跳過，不再重壓

### 🎨 其它
- 明 / 暗主題一鍵切換（記憶設定）
- 繁中 / English 雙語
- 背景處理完成通知

## 📖 使用說明

### 1. 選擇來源與輸出資料夾
- 在「**選擇來源**」區塊：**選擇 JPG**（多選）或 **掃描來源資料夾**。
- 在「來源 / 輸出資料夾」卡片可預先設定預設路徑（即時監測需先設來源資料夾）。

### 2. 選擇壓縮模式
- **手動**：拖曳品質與解析度滑桿，即時預覽。
- **自動 10MB**：輸入目標大小（MB），設定品質 / 解析度下限與容量策略。

### 3. 背景自動化
- 選擇監測模式：關閉 / 即時 / 定時 / 兩者。
- 定時模式可調掃描間隔；即時模式需設定**來源資料夾**。

### 4. 處理檔案
- 看完清單 → 按「開始處理」（掃描流程會自動列表→依序處理）。
- 處理中可 **暫停 / 繼續**、**停止**。
- 「是否重新處理」開關：預設**關閉**；**開啟**時即使輸出已存在也會重新壓縮。

### 5. 看結果
- 每個项目旁顯示：狀態、原始 / 輸出大小、壓縮率、使用的品質 / 解析度。
- 輸出檔預設為「**原檔名_slimmed.jpg**」，不覆蓋原始檔。
